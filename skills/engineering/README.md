# Engineering Skills

User-invoked:

- [`git-auto-commit`](./git-auto-commit/SKILL.md) — Analyze current Git changes and create a safe bilingual local commit. Includes secret detection, merge conflict detection, and staged/unstaged diff statistics.
- [`deep-review`](./deep-review/SKILL.md) — Production-level read-only code review via direct git diff, severity×confidence weighted risk score, and merge recommendation. No script dependency.
