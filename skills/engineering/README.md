# Engineering Skills

User-invoked:

- [`git-auto-commit`](./git-auto-commit/SKILL.md) — Analyze current Git changes and create a safe bilingual local commit. Includes secret detection, merge conflict detection, and staged/unstaged diff statistics.
- [`deep-review`](./deep-review/SKILL.md) — Perform a read-only, defect-first code review of a specified code change and return every actionable finding. Covers correctness, security, performance, API design, error handling, test coverage, and maintainability.
