# Engineering Skills

User-invoked:

- [`git-auto-commit`](./git-auto-commit/SKILL.md) — Analyze current Git changes and create a safe bilingual local commit. Includes secret detection, merge conflict detection, and staged/unstaged diff statistics.
- [`deep-review`](./deep-review/SKILL.md) — Perform a production-level, read-only code review of uncommitted changes. Covers correctness, reliability, security, performance, architecture, testing, regression, observability, and deployment safety. Classifies findings by severity and confidence with a final risk score and merge recommendation.
